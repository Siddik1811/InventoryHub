# InventoryHub

InventoryHub is a full-stack inventory management application built using React and Node.js with Express. The application demonstrates frontend-backend communication, REST API integration, structured JSON responses, error handling, and performance-focused implementation.

## Project Overview

InventoryHub provides a simple dashboard for managing inventory products.

Users can:

- View inventory products
- Search products
- Filter products by category
- Add new products
- Edit existing products
- Delete products
- View inventory statistics
- Monitor low-stock items
- View total inventory value

## Technologies Used

### Frontend

- React
- Vite
- JavaScript
- CSS
- Lucide React

### Backend

- Node.js
- Express.js
- CORS
- REST API
- JSON file-based data storage
